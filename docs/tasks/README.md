# 任务跟踪目录

本目录对框架开发这一长程任务做**文档级跟踪**，核心文件：

| 文件 | 作用 |
|---|---|
| `TASKS.md` | 总任务列表：每个阶段一个条目，含目标/状态/负责人 |
| `PROGRESS.md` | 开发日志：按日期追加，记录进展、阻塞、问题 |
| `DECISIONS.md` | 架构决策记录（ADR）：每个决策含背景/选择/理由 |

## 工作流

- 每个**阶段**在 `TASKS.md` 建条目，状态：`未开始 → 进行中 → 已完成`
- 每个**工作单元**（一个阶段内的实现）完成后，在 `PROGRESS.md` 记一笔
- 重要**设计决策**（接口、架构、依赖选型）写入 `DECISIONS.md`，不再回头讨论
- 阶段完成时同步更新 `IMPLEMENTATION_PLAN.md` 对应状态

## 约定

- 时间戳统一 `YYYY-MM-DD`
- 状态变更必须带日期
- 一个阶段条目的状态只有全部成功标准达成才置"已完成"
