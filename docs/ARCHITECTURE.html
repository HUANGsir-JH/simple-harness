simple-harness 的无状态运行时

共享的 Agent 与 middleware chain 不持有会话。每个回合由 Session 生成独立 RuntimeContext，把会话中的消息、状态和落盘能力作为调用上下文传入。

Hook 在 ReAct loop 中的位置

五个 onion hook 覆盖的范围从整个回合逐步收窄；onSystemPrompt 是在进入循环前顺序执行的独立 transformer pipeline，而不是 onion 的一层。

并发边界：共享的是 Agent、middleware chain、client 和工具注册表；每次调用的新 RuntimeContext 才携带某个会话的引用。因此切换会话是替换 rc，并发运行要求每个 goroutine 使用独立 rc。

恢复边界：SessionMiddleware 在回合前按需加载 AgentState，并在回合后原子保存。transcript writer 将用户输入和块级事件异步写入 JSONL；恢复时从持久化目录重建会话。
