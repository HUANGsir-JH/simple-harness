## DeepSeek 端点实测结论（重要证据，阶段 B/C 都依赖）

用 Python 原始 HTTP 测 `~/.harness/config.yaml` 的 `deepseek-claude`（base_url `https://api.deepseek.com/anthropic`，模型 `deepseek-v4-flash`，context_window 1M）：

- 返回 thinking 块**含 signature**；usage 含 input/output/cache 字段。
- **thinking 块（含 signature）回传 → 200**，且计入 `input_tokens`（99→136）。
- thinking 块**不带 signature 也 200**（DeepSeek 宽松）；thinking + tool_use 同消息回传 200；`include: ["reasoning.encrypted_content"]` 参数 200。
- ⇒ **完整回传 thinking 可行**；1M 窗口足够容纳大 thinking（DeepSeek thinking 可达 1.6万~3万字符/轮）。

注意：本机出站有代理/系统注入 header，Python 测试需 `ssl._create_unverified_context()`；Go harness 的 anthropic 适配层已用 `option.WithAuthToken` 覆盖（ADR-019，勿动）。

## 阶段 B：thinking 完整回传（ADR-025 修订）——下一步

**关键文件**：
- `internal/provider/anthropic_stream.go` — 流适配，`content_block_start` 的 thinking 块 signature 在 `ev.ContentBlock.Signature`（SDK union `ContentBlockStartEventContentBlockUnion` 已含，v1.61.0）
- `internal/provider/interface.go` — `Event` 加 `Signature string` 字段（thinking_done 用）
- `internal/messages/messages.go` — `Message` 加 `ThinkingSignature string`（JSON tag，`json:"thinking_signature,omitempty"`）
- `internal/events/events.go` — `Event` 加 `Signature string`（thinking_done 用）
- `internal/session/transcript.go` — `Line` 加 `Signature string`；`OnAgentEvent` 的 thinking 行写 signature
- `internal/session/load.go` — `loadHistoryFile` 的 `LineTypeThinking` 读 signature → `Message.ThinkingSignature`（resume 恢复）
- `internal/agent/agent.go` — `sample` 在 `EventThinkingDone` 捕获 signature → `Message.ThinkingSignature`
- `internal/provider/anthropic_messages.go` — `toAnthropicAssistantMessage` 重放 thinking 块

**实现要点**：
1. **捕获**：`anthropic_stream.go` `content_block_start` 对 `cb.Type == "thinking"` 记 `pb.signature = ev.ContentBlock.Signature`（pendingBlock 加字段）；`content_block_stop` 的 thinking 分支 `s.cur = Event{Type: EventThinkingDone, Text: ..., Signature: pb.signature}`。
2. **存储**：`Message.ThinkingSignature`；transcript `Line.Signature`（thinking 行），resume 恢复。
3. **重放**：`toAnthropicAssistantMessage` 首块插入 `anthropic.ContentBlockParamUnion{OfThinking: &anthropic.ThinkingBlockParam{Signature: m.ThinkingSignature, Thinking: m.Thinking}}`——**仅 `m.ThinkingSignature != ""` 时重放**（严格端点兼容；DeepSeek 恒返回 signature）。**thinking-only assistant 不再跳过**：`toAnthropicMessages` 的跳过条件从"content 空 + 无 tool_calls"改为"content 空 + 无 tool_calls + Thinking 空"。
4. **估算镜像**（阶段 C 用到，可顺带）：估算要含 Thinking（镜像实际发送）。

**测试**：stream 测试（signature 捕获）、anthropic_messages 测试（重放顺序 thinking 在 text/tool_use 前、thinking-only 不跳过）、resume 恢复 signature、真实 API 冒烟（长 thinking 会话回传不 400）。
**版本**：0.7.1 → 0.7.2。
**文档**：DECISIONS 记 ADR-025 修订；PROGRESS 加条目。
