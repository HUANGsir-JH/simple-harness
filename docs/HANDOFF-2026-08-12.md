## 已确认决策（ADR-037 摘要，全部用户拍板）

| 决策点 | 结论 |
|---|---|
| 压缩触发 | context_window **85% 硬编码**（无配置）；实际 usage（LastContextTokens）驱动 + 估算（bytes/4 含 thinking）兜底 |
| 压缩方式 | **直接 LLM 摘要式**（不做 v1 TokenBudget）；自动（onReasoning before）+ 手动 `/compact` |
| 压缩后保留 | **纯占位**——conversation = 单一 summary user 消息；"保留最新信息"由摘要 prompt 交 LLM（opencode 结构化模板） |
| 摘要失败 | **跳过压缩 + 终止本次 agent run**；Esc 中断压缩 = 摘要失败同处理；**绝不重写 conversation** |
| 摘要请求发送 | **codex 方式**：完整 conversation（经 toAnthropicMessages 含 thinking 回传）+ 摘要 prompt 尾 user，无工具，max_tokens 4096 |
| previous summary | `AgentState.Summary` 作 `<previous-summary>` 更新式续接（opencode buildPrompt 同款） |
